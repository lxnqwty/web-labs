# Лабораторная работа №3 — Vue: каркас и три экрана

## Реализованный результат

Клиентская часть проекта создана в каталоге `frontend/` на Vue 3, JavaScript и Vite. Приложение запускается командой `npm run dev` и использует стандартный адрес `http://localhost:5173`.

### Экраны

1. **Список активностей:** таблица с номером, темой, категорией (`categoryId`) и статусом. Начальный массив содержит три демонстрационные записи. Строки выводятся директивой `v-for` с `:key="item.id"`. Доступны поиск по номеру/теме и фильтр по статусу.
2. **Создание активности:** семантическая форма с полями `title`, `categoryId`, `description`, подписями `label` и кнопкой отправки. Поле темы получает фокус при открытии экрана. Валидация длины темы (5–80) и описания (10–500) задана атрибутами HTML.
3. **Вход:** семантическая форма с полями `login` и `password`. Реальная авторизация на данном этапе не выполняется.

Переключение экранов выполняется реактивным состоянием Vue `ref` и директивами `v-if` / `v-else-if`. Данные списка хранятся в реактивном массиве.

## Согласование с лабораторной работой №2

В методическом примере поле справочника называется `siteId`. В проекте из ЛР2 предметная сущность называется `Category`, а поле внешнего ключа — `categoryId`. Поэтому форма и таблица используют `categoryId`, как зафиксировано в `docs/data-model.md` и `docs/api-contract.md`. Поля `title` и `description` совпадают с контрактом API.

Статусы соответствуют словарю проекта: `New`, `InProgress`, `Closed`, `Cancelled`.

## Семантика и доступность

- Основная рабочая область использует элемент `<main>`.
- Формы создания и входа размечены через `<form>`.
- Каждое поле формы имеет связанный `<label>`.
- Список активностей представлен таблицей `<table>`.
- Для повторяющихся строк `v-for` указан устойчивый `:key`.
- При переходе к созданию фокус устанавливается на поле `title`.
- Пользовательский текст выводится интерполяцией Vue, без `v-html`.

## Проверка запуска

Из корня репозитория выполнить:

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно `http://localhost:5173`. Для проверки production-сборки выполнить `npm run build`.

## Ограничения

Данные демонстрационные. Добавленная запись существует только в состоянии текущего приложения и исчезает после перезагрузки страницы. Форма входа пока не обращается к серверу. Интеграция с ASP.NET Core API и PostgreSQL не входит в объём ЛР3.
