# web-labs

ТРИС-1-23 Карабаев Андрей Маратович

Учебный проект: цифровой профиль студента для учёта учебной, научной и проектной активности.

**Стек проекта:** Vue 3 + Vite (клиент, ЛР3), ASP.NET Core (планируемый API), PostgreSQL (планируемая БД).

## Лабораторная работа №3 — клиентское приложение

В папке `frontend/` находится каркас клиентского приложения на Vue 3 и JavaScript. Реализованы три экрана:

- **Мои активности** — таблица записей с номером, темой, категорией и статусом; поиск и фильтрация.
- **Новая активность** — форма с полями `title`, `categoryId`, `description`.
- **Вход в профиль** — форма логина и пароля (пока без серверной авторизации).

Имена полей согласованы с контрактом API из `docs/api-contract.md`: в модели проекта используется `categoryId` (сущность `Category`), поэтому он заменяет учебное условное поле `siteId` из примера методички. Статусы: `New`, `InProgress`, `Closed`, `Cancelled`.

### Требования

- Node.js LTS и npm.
- Установка и запуск выполняются из корня репозитория:

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно `http://localhost:5173`.

Для production-сборки: `npm run build`.

### Ограничения текущего этапа

ЛР3 реализует клиентский каркас. Начальные записи демонстрационные; создание активности добавляет запись только в состояние приложения и не сохраняет её на сервере. Проверка логина и пароля, API и подключение PostgreSQL будут реализованы в следующих лабораторных работах.
