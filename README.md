# web-labs

ТРИС-1-23 Карабаев Андрей Маратович

Учебный проект: цифровой профиль студента для учёта учебной, научной и проектной активности.

**Стек:** Vue 3 + Vite + Vue Router (клиент), ASP.NET Core (планируемый API), PostgreSQL (планируемая БД).

## Лабораторная работа №4 — компоненты и маршруты Vue

В `frontend/` реализованы три маршрута:

- `/` — список активностей;
- `/new` — создание активности;
- `/login` — вход в профиль.

Общая навигация вынесена в `AppHeader.vue`, таблица — в `TicketTable.vue` и получает данные через prop `items`. Общий реактивный массив находится в `src/ticketsStore.js`.

### Запуск

Требуются Node.js LTS и npm.

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`. Каждый маршрут можно проверить прямым вводом адреса в браузере. Для production-сборки: `npm run build`.

### Ограничения

Демонстрационные данные хранятся в памяти и сбрасываются после перезагрузки. API, PostgreSQL и серверная авторизация будут подключаться в следующих работах.
