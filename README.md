# web-labs

ТРИС-1-23 Карабаев Андрей Маратович

Учебный проект: цифровой профиль студента для учёта учебной, научной и проектной активности.

**Стек:** Vue 3 + Vite + Vue Router (клиент), ASP.NET Core (планируемый API), PostgreSQL (планируемая БД).

## Лабораторная работа №5 — форма и список в памяти

В папке frontend реализованы три маршрута: / — список активностей, /new — создание активности, /login — вход в профиль.

Форма на странице /new связана с реактивным состоянием через v-model. Проверяются тема, категория и описание; корректная запись добавляется в единый массив из ticketsStore.js со статусом New. После создания приложение возвращается к списку.

### Запуск

Требуются Node.js LTS и npm.

    cd frontend
    npm install
    npm run dev

Откройте http://localhost:5173. Для production-сборки выполните npm run build.

### Ограничения

Новые записи хранятся только в памяти приложения и исчезают после перезагрузки страницы (F5). Серверное API, PostgreSQL и серверная авторизация будут подключаться в следующих работах.
